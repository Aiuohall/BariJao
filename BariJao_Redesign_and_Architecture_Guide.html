🚀 1. Executive Summary & Core Vision

BariJao was originally created to solve the dangerous black-market scam problem during Eid festival rushes in Bangladesh, allowing verified travelers to safely buy and resell spare tickets peer-to-peer.

With the v2.0 Redesign, BariJao expands into a full-scale e-ticketing platform matching Bangladesh market leaders like Shohoz.com and bdtickets.com, while preserving and elevating the signature P2P second-hand resale marketplace side-by-side.

The Dual-Model Advantage: Under ordinary travel conditions, users purchase direct official e-tickets from verified transport operators at standard fares. When festival dates sell out, the integrated P2P Resale Exchange activates, letting travelers safely transfer spare tickets without scalper gouging or duplicate ticket scams.

🏗️ 2. Architectural Pillars

🚌 1. Official E-Ticketing Engine

Direct ticket booking for Bus, Bangladesh Railway, Launch, and Domestic Airlines with real-time seat availability, live filter controls, and instant digital voucher generation.

🤝 2. P2P Resale Marketplace

Private peer-to-peer ticket exchange with masked seat numbers, private 1-on-1 chat, verified seller ratings, and anti-fraud escrow protection.

💺 3. Interactive Graphical Seat Map

Visual 2×2, 2×1 luxury business, sleeper berths, train coach, and launch cabin seat layouts with ladies-only indicators and boarding point selection.

💳 4. Bangladesh Payments & PNR Engine

Seamless checkout simulator for bKash, Nagad, Rocket, and Cards with coupon discounts (`EID2026`, `BARIJAO50`), automated PNR issuance, and 24/7 ticket lookup.

🔄 4. End-to-End User Experience

  1. Route Search: Traveler enters origin ("From"), destination ("To"), and journey date on the modern hero bar. Supports 1-click swap (⇄), fast date chips ("Today", "Tomorrow"), and category filters.
  2. Filter & Sort: Results can be filtered by Operator, Coach Class (AC / Sleeper), Max Fare slider, and sorted by Cheapest, Earliest Departure, or Highest Rating.
  3. Interactive Seat Selection: Clicking "View Seats" opens an animated visual seat layout. Users select up to 4 seats, choose boarding counter (e.g., Sayedabad, Gabtoli) and dropping counter with exact pickup times.
  4. Checkout & Promo Application: Enter primary passenger name, Bangladesh mobile number, and optional coupon code (`EID2026` for 15% off, `BARIJAO50` for ৳50 off).
  5. Payment Simulator: Complete payment via bKash (with demo OTP `123456` and PIN flow), Nagad, Rocket, or Cards.
  6. Instant Confirmed E-Ticket: Immediate issuance of a digital travel voucher with unique PNR (e.g., `BJ-BUS-485123`), QR code, barcode, and one-click printable PDF.
  7. Anytime PNR Lookup: Enter PNR or mobile number at `/check-ticket` to view, download, or reprint vouchers anytime.

💻 5. Technical Stack & Data Architecture

Layer Technologies Used Responsibilities
Frontend React 19, TypeScript, Tailwind CSS v4, Lucide Icons, Vite, React Router v7 SPA rendering, interactive seat maps, modals, checkout simulation, bilingual translations.
Backend API Node.js, Express, TypeScript (tsx runtime), Multer, JWT, bcryptjs REST API routes, auth & OTP limiter, official ticketing endpoints, P2P chat, admin APIs.
Database better-sqlite3 (with Supabase PostgreSQL support) Dual-table support: official schedules & bookings alongside user tickets and transactions.

Key Database Tables:

  • official_trips: Stores schedules, operator details, fares, seat layouts, booked seat arrays, and boarding points.
  • official_bookings: Stores confirmed tickets, unique PNR, traveler details, seat numbers, paid fares, and transaction IDs.
  • tickets: P2P community listings with original price, asking price, masked seat number, and seller verification.
  • users, messages, transactions, ratings: User authentication, private P2P chat threads, and seller reviews.

REST API Endpoints:

⚡ 6. Step-by-Step Runbook (How to Run the Web)

1. Prerequisites

  • Node.js: v18.0.0 or later (v20+ recommended)
  • Package Manager: npm (bundled with Node.js)

2. Installation & Setup

Navigate to the project root directory and ensure dependencies are installed:

cd D:\barijao
npm install

3. Running the Development Server

Launch the combined backend server and Vite frontend dev server with live hot-reloading:

npm run dev

Once launched, open your web browser and navigate to:
👉 http://localhost:3000

4. Compiling & Production Build

To verify TypeScript typings and build the optimized production assets:

npm run lint     # Runs TypeScript compiler check (0 errors)
npm run build    # Compiles production assets into /dist folder

5. Running in Production Mode

NODE_ENV=production npm start

6. Default Test Accounts & Promo Codes

  • Discount Coupons: Use EID2026 (15% off up to ৳300), BARIJAO50 (৳50 off), or SHOHOZ10 (10% off).
  • bKash Simulator: Enter any 11-digit mobile number, use OTP 123456, and enter any 5-digit PIN.
  • Admin Access: Available at /admin for administrative moderation.
